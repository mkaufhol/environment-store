<h1 align="center">Environment store</h1>

> **Version 2 is being rebuilt.** This branch contains the V2 rewrite, which is not usable yet. The released
> 0.1 line lives on `main`.

Environment Store V2 keeps environment variables in named stores (optionally encrypted) on local JSON / TOML files,
SQLite or PostgreSQL, and loads them from Python, the command line or a terminal UI.

- What V2 does: [SPEC-V2.md](SPEC-V2.md)
- How it is built: [IMPLEMENTATION-PLAN.md](IMPLEMENTATION-PLAN.md)
